# Changelog

## [1.1.0] — 2026-10-26

- Проверка серверов Telegram (DC1–DC5) во вкладке «Проверка». Если провайдер закрыл их по IP,
  программа так и пишет и подсказывает, что поможет: прокси в Telegram (MTProxy/SOCKS5) или VPN.
- «Проверка» и «Поиск блокировок» отличают блокировку по IP (до сервера не доходит даже TCP)
  от блокировки DPI и от подмены DNS — раньше всё это выглядело как «не отвечает».
- Голые IP-адреса больше не копятся в «Найдено автоматически» (туда попадали серверы Telegram):
  обход по списку им не помогает.
- Автоподбор стратегии больше не учитывает web.telegram.org (он заблокирован по IP и только портил счёт).
- В исключения по умолчанию добавлены серверы загрузок Steam (`steamcontent.com`, `steampipe.akamaized.net`).

## [1.0.0] — 2026-10-07

Первый публичный релиз.

- Программа в трее: включение/выключение обхода одной кнопкой, цветной значок-щит.
- Автозапуск вместе с Windows (служба `zapret-vn` + задача планировщика для значка).
- Защищённый DNS (DoH 8.8.8.8 / 1.1.1.1) одной галочкой.
- Редактор списков: сайты в обходе, автоматически найденные, исключения.
- Автообнаружение блокировок (3 сбоя подряд → сайт сам добавляется в обход).
- Поиск блокировок среди ~70 популярных сайтов у текущего провайдера.
- Автоподбор стратегии обхода (10 стратегий).
- Проверка доступности Steam / Roblox / Telegram / Discord.
- Один самодостаточный `ZapretVN.exe`: zapret v72.13, WinDivert и списки вшиты внутрь.
- Автообновление параметров службы при запуске новой версии.
